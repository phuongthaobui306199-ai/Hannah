# Hannah English Center — Landing VSTEP (LP-002)

## Chạy thử

```powershell
python -m http.server 4174
```

Chạy trong thư mục này rồi mở `http://localhost:4174`. Hoặc mở thẳng `index.html` bằng trình duyệt.

## Cấu trúc

- `index.html`: nội dung 7 phần (Hero, Vấn đề, Giải pháp, Kết quả, Chương trình, FAQ, Đăng ký).
- `styles.css`: giao diện đỏ – trắng be – đen, Playfair Display + Be Vietnam Pro, responsive.
- `script.js`: kiểm tra form và lưu lead demo vào `localStorage`.
- `hannah-vstep-share.html`: bản một file (gộp CSS/JS) dùng để đăng Artifact chia sẻ.

## Trước khi xuất bản

- Nối form với hệ thống nhận lead chính thức.
- Thay wordmark chữ bằng file logo chính thức.
- Nhờ Hannah rà cấu trúc đề VSTEP, nội dung "lớp học tập trung vào" và các câu FAQ.
- Không thêm học phí, lịch khai giảng, sĩ số, cam kết đầu ra khi chưa được xác nhận.
